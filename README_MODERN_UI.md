## 🔧 Customization

### Change Colors
```javascript
// Find all instances of:
linear-gradient(135deg, #667eea, #764ba2)

// Replace hex codes with your colors
linear-gradient(135deg, #YOUR_COLOR1, #YOUR_COLOR2)
```

### Adjust Animation Speed
```javascript
// Find all instances of:
animation: "fadeInUp 0.8s ease-out"

// Change duration (0.8s → your duration)
animation: "fadeInUp 1s ease-out"
```

### Modify Spacing
```javascript
// Find all instances of:
padding: "100px 20px"

// Change values as needed
padding: "80px 20px" // Reduce
padding: "120px 20px" // Increase
```
