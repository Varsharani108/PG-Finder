## 🔄 Animation Performance Tips

### What Makes Animations Smooth
1. **Transform-based:** Uses GPU acceleration
2. **Opacity changes:** No layout recalculation
3. **Proper timing:** 0.3s-0.8s duration
4. **Easing functions:** ease-out for entrance, ease-in for exit
5. **Hardware acceleration:** Via will-change

## 📞 Support & Troubleshooting

### Common Issues & Solutions

**Q: Animations feel choppy on mobile**
A: Reduce animation duration or use `will-change` CSS property

**Q: Gradient not showing**
A: Ensure modern browser; gradient uses linear-gradient()

**Q: Form not submitting**
A: Check `submitContact()` API function exists

**Q: Icons not showing**
A: Verify Lucide icons are imported correctly

**Q: Responsive grid not working**
A: Check that parent has proper width/padding
